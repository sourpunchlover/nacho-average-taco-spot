# Nacho Average Taco Spot 🌮

## Description
Nacho Average Taco Spot is a point of sale application for a custom taco shop.
Customers can fully customize their taco orders, choose from signature tacos,
add drinks, and chips & salsa. Orders are saved as receipts with a unique
timestamp filename.

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run `MainApp.java`
4. Follow the on-screen prompts to place an order

## Features
- Custom taco builder with premium and regular toppings
- Signature tacos (The OG, The Baja Babe, The Heavyweight)
- Customize signature tacos by adding or removing toppings
- Add drinks and chips & salsa
- Order validation
- Receipt saved to `orderreceipts/` folder
